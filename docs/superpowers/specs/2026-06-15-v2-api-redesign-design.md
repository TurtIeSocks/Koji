# Koji v2 API Redesign — Design

**Date:** 2026-06-15
**Branch:** claude/v2
**Status:** Approved design (delegate mode). Next step: writing-plans → phased implementation.

---

## 1. Context & Goals

Koji is a self-hosted geofence / routing / clustering tool for Pokémon-GO scanner stacks. Its
HTTP surface (actix-web, `koji-service`) currently carries **three overlapping designs**:

- **v1** (`/api/v1/*`, 40 routes) — the legacy surface. **Still the active one**: the in-repo React
  frontend (`client/src/services/fetches.ts`) consumes v1 (`/calc`, `/convert`, `/s2`) plus
  `/internal/admin` and `/internal/data`.
- **backend-v2** (`/api/v2/*`, 52 routes) — a hasty port of v1. **Zero in-repo consumers.** Carries
  v1 disease: untyped `serde_json::Value` bodies, RPC-in-path (`/calc/{mode}/{category}`), a
  sync/async toggle (`?wait=1` returns 200-result *or* 202-job *or* 504-"timeout"), two enqueue
  paths, a split-brain envelope (enveloped JSON for CRUD, raw GeoJSON for geometry reads), no 404
  on reads, `rows_affected` DB-leaks on delete, no pagination, no `Location` headers.
- **`openapi.yaml`** — a hand-maintained spec describing a cleaner *intent* the handlers don't honor
  (it promises 404 on read; the code returns 500/empty).

**Goal:** collapse all three into **one correct, best-practice `/api/v2` surface**, and delete v1 +
`/internal/*`. "Full carnage, no loyalty to the current design" — but sequenced so the active surface
(v1) dies **last**, after the frontend migrates, so nothing breaks mid-flight.

### Non-goals

- Redesigning the response envelope (it is a deliberate cross-system standard — see §2).
- Changing the Koji↔Dragonite event contract (`area.geofence_updated` / `area.route_updated`
  payloads are an external contract with Dragonite).
- Adding multi-tenant auth, rate-limiting, or CORS (YAGNI for a self-hosted single-secret tool;
  see §11).

## 2. Locked conventions

| Concern | Rule |
|---|---|
| **Success envelope** | `{ "status": "ok", "data": …, "meta": …? }`. Deliberate **Dragonite-v2 parity** (Dragonite dropped JSend for v2; Koji follows). Not redesigned. |
| **Error envelope** | `{ "status": "error", "error": { "code", "message", "field"? } }`. `code` is a stable machine string (`not_found`, `invalid_request`, `unprocessable`, `conflict`, `timeout`, `unauthorized`, `internal_error`). |
| **GeoJSON is enveloped** | The default GeoJSON `Feature`/`FeatureCollection` response goes **inside** `data`. The old "raw, un-enveloped for v1 drop-in" default is dropped (v2 has no v1 consumers). Exception: explicit export formats — see §6.4. |
| **Resources are nouns, plural** | `/geofences`, `/routes`, `/jobs`, `/projects`. Verbs only for genuine actions (`/{id}/publish`). |
| **Params are params** | `mode`, `category` are request **fields**, never URL path segments. |
| **Status codes are semantic** | `201`+`Location` on create · `204` on delete · `404` on missing read/update/delete · `400` malformed · `422` semantically invalid · `409` conflict · `202` async accepted. Never 200-for-error; never 504-as-"still-running". |
| **Typed bodies** | No `web::Json<serde_json::Value>`. Every write has a typed Create/Patch DTO, validated at the boundary. |
| **Auth** | `Authorization: Bearer <KOJI_SECRET>` (single shared secret) **or** an admin session cookie. Liveness/readiness probes and the OpenAPI doc are unauthenticated. |
| **Case** | JSON wire is `camelCase` (matches existing v2 arg-groups). URL paths are `kebab-case`. |

## 3. Resolved decisions (the approved assumptions)

| # | Decision |
|---|---|
| A1 | Envelope stays Dragonite-v2 parity `{status,data,meta?}` — not redesigned. |
| A2 | **Single-surface:** v2 replaces v1; v1 + `/internal/*` deleted after the frontend migrates (P5→P6). |
| A3 | **Calc folds into `/jobs`** — no `/calc` namespace; `mode`/`category` are body fields; job creation is always async (`202`+`job_id`); `?wait=N` long-polls and returns the **job resource** (never a 504 error). |
| A4 | Drop the opaque `{kind,payload}` enqueue; one typed job body (becomes a tagged enum if more job kinds ever appear). |
| A5 | Typed Create/Patch DTOs generated by a `#[koji_resource]` proc-macro; no `Value` bodies. |
| A6 | A local `ServiceError` + `ResponseError` impl drives correct error→status. |
| **A7** | **Keep the export formats for scanner-tool compatibility, exposed via `?format=`.** Default/`geojson` → enveloped GeoJSON; explicit export formats (`poracle`, `sql`, `text`, `array`, …) → **raw body, drop-in compatible** (Content-Type per format). Raw is consumer opt-in, not the default. |
| A8 | Drop the dev-only `?internal=` knob from the public surface. |
| A9 | `204` on DELETE (drop `rows_affected`), `201`+`Location` on create, `404` on missing. |
| A10 | Pagination = `?limit=&offset=` now, emitting the already-reserved `meta` block. |
| A11 | scanner-data → sub-resource `GET /api/v2/geofences/{id}/scanner-data`. |
| A12 | Regroup `/geo/*` → `/geometry/*`; lift `/s2/*` to its own top-level namespace. |
| A13 | plugins id → path segments `/plugins/{kind}/{name}` (drop the `{kind}:{name}` colon). |
| A14 | Auth unchanged; fold `/config/login\|logout` → `/api/v2/auth/login\|logout`. Scoped/per-user keys = future. |
| A15 | Code-first OpenAPI (utoipa) — the spec is generated from the typed handlers so it cannot drift. |
| A16 | No rate-limiting / CORS now. |
| A17 | SSE `GET /api/v2/jobs/{id}/events` included for live UI progress. |

## 4. The v2 surface

All paths are under `/api/v2`. All require auth unless marked *(unauth)*. All JSON responses use the
§2 envelope unless marked *(raw)*.

### 4.1 Jobs (calc folded in)

| Method | Path | Request | Success | Errors |
|---|---|---|---|---|
| POST | `/jobs` | `CalcJobRequest` (§5.1) | `202` `{job_id}` + `Location: /api/v2/jobs/{id}` | 400, 401, 422 |
| GET | `/jobs` | — (`?limit=&offset=&status=`) | `200` `Job[]` + `meta` | 401 |
| GET | `/jobs/{id}` | — | `200` `Job` (§5.2) | 401, 404 |
| GET | `/jobs/{id}?wait=N` | — | `200` `Job` (long-poll up to N s; running or terminal record) | 400, 401, 404 |
| GET | `/jobs/{id}/events` | — (SSE) | `200` `text/event-stream` of `Job` snapshots | 401, 404 |
| DELETE | `/jobs/{id}` | — | `202` `{canceled: id}` | 401, 404 |
| GET | `/algorithms` | — | `200` `{clustering[], routing[], bootstrap[]}` (plugins included) | 401 |

**Sync bridge correction:** there is no result-or-job-id polymorphism. `POST /jobs` *always* returns
a job id. `GET /jobs/{id}?wait=N` blocks up to N seconds (server-capped, default cap ~290 s) and
returns the **job resource** — a `running` record on timeout (HTTP `200`, not `504`), a terminal
record (`succeeded`/`failed`/`canceled`) once done. A succeeded job's `result` carries
`{ data: FeatureCollection|null, stats }`.

### 4.2 Typed CRUD resources

`{resource}` ∈ `geofences` · `routes` · `projects` · `properties` · `tile-servers`. All five share
the generated shape (§6.1):

| Method | Path | Request | Success | Errors |
|---|---|---|---|---|
| GET | `/{resource}` | — (`?limit=&offset=`; geo: `?format=`) | `200` list + `meta` | 401 |
| POST | `/{resource}` | `Create<R>` DTO (§5.3) | `201` record + `Location` | 400, 401, 422 |
| GET | `/{resource}/{id}` | — (geo: `?format=`) | `200` record | 401, 404 |
| PATCH | `/{resource}/{id}` | `Patch<R>` DTO (all-optional) | `200` record | 400, 401, 404, 422 |
| DELETE | `/{resource}/{id}` | — | `204` | 401, 404 |

- **geofences / routes** are geometry-bearing: list `data` is a `FeatureCollection`, get `data` is a
  `Feature` (default), or a raw export with `?format=` (§6.4).
- **geofences** keep hierarchy traversal via a single `?descend=N` param (replaces the
  mutually-exclusive `?depth=`/`?level=` pair; `0`/absent = no descent).
- **projects / properties / tile-servers** return plain JSON records in `data`.

**Publish actions:**

| Method | Path | Success | Errors |
|---|---|---|---|
| POST | `/geofences/{id}/publish` | `202` `{event_id, topic, dragonite_area_id}` | 401, 404 (unknown), 422 (unlinked) |
| POST | `/routes/{id}/publish` | `202` `{event_id, topic, dragonite_area_id, mode}` | 401, 404, 422 |

`/{id}` accepts a numeric id or a name on reads/publish; writes (PATCH/DELETE) require a numeric id.

### 4.3 Geometry transforms

Stateless function endpoints (honest RPC — no underlying resource). Typed bodies, enveloped GeoJSON
by default, `?format=` for raw exports.

| Method | Path | Request | Success |
|---|---|---|---|
| POST | `/geometry/convert` | `GeometryArgs` (§5.4) | `200` GeoJSON / raw |
| POST | `/geometry/simplify` | `GeometryArgs` | `200` GeoJSON / raw |
| POST | `/geometry/merge-points` | `GeometryArgs` | `200` MultiPoint / raw |

### 4.4 S2

| Method | Path | Request | Success |
|---|---|---|---|
| POST | `/s2/{level}` | `BoundsArg` `{minLat,minLon,maxLat,maxLon, ids?}` | `200` `{cells[]}` |
| POST | `/s2/circle-coverage` | `CoverageArgs` `{lat,lon,radius?,level}` | `200` coverage |
| POST | `/s2/cell-coverage` | `CoverageArgs` `{lat,lon,size?,level}` | `200` `{cellIds[]}` |
| POST | `/s2/polygons` | `string[]` (cell ids) | `200` `{polygons[]}` |

### 4.5 Scanner data

| Method | Path | Request | Success | Errors |
|---|---|---|---|---|
| GET | `/geofences/{id}/scanner-data` | — (`?category=&lastSeen=`) | `200` `{points: [[lat,lon],…]}` | 400, 401, 404 |

`category` ∈ `gym` · `pokestop` · `spawnpoint` · `station` · `fort` (fort = gym+pokestop+station).
The geofence `{id}` (id or name) supplies the bounding area.

### 4.6 Plugins

| Method | Path | Request | Success | Errors |
|---|---|---|---|---|
| GET | `/plugins` | — | `200` `Plugin[]` | 401 |
| GET | `/plugins/{kind}/{name}` | — | `200` `Plugin` | 401, 404 |
| PATCH | `/plugins/{kind}/{name}` | `PluginPatch` `{enabled?, argsDefault?, description?}` | `200` `Plugin` | 401, 404, 422 |
| DELETE | `/plugins/{kind}/{name}` | — (reset overlay to disk defaults) | `204` | 401, 404 |

`Plugin` = merged disk-manifest (`entrypoint`/`interpreter`/`protocol`/`version`, read-only) +
DB overlay (`enabled`/`argsDefault`/`description`). `kind` ∈ `clustering` · `routing` · `bootstrap`.

### 4.7 Auth & meta

| Method | Path | Request | Success | Notes |
|---|---|---|---|---|
| POST | `/auth/login` | `{password}` | `200` (sets session) | from `/config/login` |
| POST | `/auth/logout` | — | `204` | from `/config/logout` (was a 302) |
| GET | `/auth/me` | — | `200` `{authenticated, via}` | session/bearer introspection |
| GET | `/openapi.yaml` *(unauth)* | — | `200` `text/yaml` | generated (§6.5) |

### 4.8 Health (top-level, unauth)

| Method | Path | Success |
|---|---|---|
| GET | `/healthz` | `200` (liveness, empty body) |
| GET | `/readyz` | `200` if DB reachable, else `503` |

## 5. Request / response types

### 5.1 `CalcJobRequest` (POST /jobs body)

Discriminated by the `mode` field (replaces the path segment + the boundary tag-injection hack):

```jsonc
{
  "mode": "cluster" | "route" | "reroute" | "bootstrap" | "routeStats" | "<plugin>",
  "category": "pokestop" | "gym" | "spawnpoint" | "station" | "fort",  // default "pokestop"; ignored when points are pre-supplied
  "area": <GeoInput>?,             // geofence name | GeoJSON | geometry  (cluster/route/bootstrap)
  "dataPoints": <DataPointsArg>?,  // pre-resolved points (cluster/route/reroute/routeStats)
  "clusters": <DataPointsArg>?,    // REQUIRED for reroute + routeStats
  "clustering": <ClusteringArgs>?, // radius, minPoints, maxClusters, mode, calculationMode, s2Level, s2Size, clusterSplitLevel, centerClusters, geneticPostProcessing, pluginArgs
  "routing":    <RoutingArgs>?,    // sortBy, routeSplitLevel, pluginArgs
  "bootstrap":  <BootstrapArgs>?,  // bootstrap mode: calculationMode, radius, s2Level, s2Size, pluginArgs
  "output":     <OutputArgs>?,     // returnType, saveToDb, saveToScanner, saveToScannerOnly, simplify
  "dataFilter": <DataFilterArgs>?, // lastSeen, tth
  "dev":        <DevArgs>?,        // bypassAdaptivePartition, benchmarkMode
  "parent": <UnknownId>?,
  "instance": <string>?,
  "radius": <number>?,             // reroute/routeStats override (default 70)
  "minPoints": <number>?           // routeStats (default 1)
}
```

Server validates `mode`→required-fields (e.g. `reroute`/`routeStats` require `clusters`) and rejects
violations with `422`. Arg-group structs already exist in `requests/groups.rs`; this reuses them with
`mode`/`category` promoted to top-level fields. The CalcRequest tagged enum (`requests/ops.rs`) is
retagged on the `mode` field rather than the path.

### 5.2 `Job` (GET /jobs/{id})

```jsonc
{
  "id": "<ulid>",
  "kind": "calculate",
  "status": "queued" | "running" | "succeeded" | "failed" | "canceled",
  "progress": 0.0,              // [0,1]
  "phase": "clustering"?,       // coarse marker
  "result": { "data": <FeatureCollection|null>, "stats": { … } }?,  // present when succeeded
  "error": "<message>"?         // present when failed
}
```

### 5.3 `Create<R>` / `Patch<R>` DTOs (derived from sea-orm Models)

Generated per resource (§6.1). `Patch<R>` = every `Create<R>` field made optional. Server-derived
fields (`id`, `created_at`, `updated_at`, derived `geo_type`/`points`, the `dragonite_area_id` link)
are never accepted on create.

| Resource | `Create` fields (required **bold**) |
|---|---|
| geofence | **name**, **mode**, **geometry**, parent?, projectIds?, properties? |
| route | **geofenceId**, **name**, **mode**, **geometry**, description? |
| project | **name**, apiEndpoint?, apiKey?, scanner?, description? |
| property | **name**, **category**, defaultValue? |
| tile-server | **name**, **url** |

`mode` ∈ `unset`·`pokemon`·`quest`·`fort`. `category` (property) ∈ `string`·`integer`·`boolean`·`float`·`database`.

### 5.4 `GeometryArgs`

```jsonc
{ "area": <GeoInput>, "simplify": <bool>?, "instance": <string>?, "benchmarkMode": <bool>? }
```

(`returnType` removed from the body — format negotiation is the `?format=` query, §6.4.)

## 6. Cross-cutting machinery (built once, P0)

### 6.1 `#[koji_resource]` proc-macro

The drift-killer. Applied to each resource module, given the sea-orm `Model`, it generates:

- `Create<R>` and `Patch<R>` DTOs (typed, `camelCase`, `serde`-validated).
- Boundary validation (required-field + enum-parse → `400`/`422`).
- The five actix handlers (list/get/create/update/delete) wired to: the typed DTOs, the §2 envelope,
  `201`+`Location`, `204`, `404`-on-missing, `?limit=&offset=`+`meta`.
- For geometry-bearing resources, the `?format=` negotiation hook (§6.4).

The 5 CRUD resources stop being 5 hand-copied handler sets — one macro is the single source of truth,
so they cannot drift. (Reuses the `macros` crate that already hosts `StrEnum`, `fort_query`,
`crud_query`.) Resource-specific endpoints (`/publish`, geofence `?descend=`) are hand-written
*alongside* the generated set, not replacing it.

### 6.2 `ServiceError` + `ResponseError`

A local enum in `koji-service` (orphan-rule-safe — we own it):

```rust
enum ServiceError {
    NotFound { field: &'static str, message: String },   // → 404 not_found
    Invalid  { field: Option<String>, message: String }, // → 400 invalid_request
    Unprocessable { field: Option<String>, message: String }, // → 422 unprocessable
    Conflict(String),                                    // → 409 conflict
    Db(#[from] sea_orm::DbErr),                           // → 500 internal_error
    Model(#[from] koji_db::ModelError),                  // → 500 (or mapped per variant)
}
impl actix_web::ResponseError for ServiceError { /* → §2 error envelope + status */ }
```

Kills the ~26 `.map_err(actix_web::error::ErrorInternalServerError)` calls and the wrong-500s on
missing resources. (This is the DRY-scan's previously-skipped "5b" — back in scope now that we own
the wrapper type.)

### 6.3 Pagination

Implement the already-reserved `meta` block: `?limit=` (default 50, cap 500) + `?offset=` (default 0)
on every list endpoint. `meta = {total, page, perPage, totalPages, hasNext, hasPrev}`. Cursor
pagination is a future option (§11) if any list outgrows offset.

### 6.4 `?format=` negotiation (resolved A7)

On geometry-bearing reads (`/geofences`, `/routes`, `/geometry/*`):

- **absent | `geojson` | `feature` | `featurecollection`** → enveloped GeoJSON in `data` (§2 default).
- **explicit export format** (`text`, `alttext`, `array`, `multiarray`, `struct`, `multistruct`,
  `geometry`, `geometryvector`, `featurevector`, `poracle`, `poraclesingle`, `sql`) → **raw body**,
  not enveloped, drop-in compatible with existing scanner tooling. Content-Type per format
  (`sql` → `text/plain`; array/struct forms → bare `application/json`).

Rationale: the export formats exist to feed external scanner tools that expect the bare shape;
enveloping them would break those consumers. Raw is therefore preserved but made **opt-in** (you only
get it when you ask), instead of v1's implicit raw-by-default. `?rt=` is renamed to `?format=`.

### 6.5 Code-first OpenAPI

Replace the hand-maintained `openapi.yaml` with a spec **generated from the typed handlers**
(`utoipa` annotations on the handler fns + DTOs). The doc can no longer drift from the
implementation. `GET /api/v2/openapi.yaml` serves the generated document.

## 8. Phased rollout

Each phase ends green (per-crate `cargo clippy` + `cargo test`; `koji-wasm` verified on the **host**
target only — never `--target wasm32`, which is a TLS-link false-failure trap; DB-touching tests
gated with `--no-run` where no DB is available). Phases land as separate commits.

| Phase | Delivers | Gate |
|---|---|---|
| **P0** | Machinery: §2 envelope helper, `ServiceError`+`ResponseError`, `#[koji_resource]` macro, pagination, `?format=` negotiator, utoipa scaffolding. No endpoint behavior change. | macro unit tests; existing suites green |
| **P1** | Jobs: fold calc→`/jobs`, typed `CalcJobRequest`, always-async, `?wait` returns Job, `/jobs` list, `/jobs/{id}/events` SSE, `/algorithms`. | job lifecycle tests; sync-bridge returns Job not 504 |
| **P2** | The 5 CRUD resources regenerated via the macro (typed DTOs, 404/204/`Location`, pagination, envelope-uniform); `/publish` kept; geofence `?descend=`. | CRUD + validation tests; 404/422 paths |
| **P3** | `/geometry/*` + `/s2/*` (typed bodies, envelope, `?format=`); `/geofences/{id}/scanner-data`. | transform + scanner-data tests |
| **P4** | plugins re-path; `/auth/*`; `/healthz`+`/readyz`; generated `openapi.yaml`. | plugin overlay tests; spec-gen builds |
| **P5** | Migrate the frontend (`client/src/services/fetches.ts`) off v1+`/internal` → v2. | frontend builds; manual smoke of map/admin/calc flows |
| **P6** | **Carnage:** delete `public/v1/*`, `LegacyArgs`, `/internal/data`, `/internal/admin`, redundant health. | full workspace green; no dead refs |

## 9. Frontend migration (P5)

`client/src/services/fetches.ts` is a centralized hand-written wrapper (~11 functions, no codegen).
Touch points:

- `clusteringRouting()` / bootstrap → `POST /api/v2/jobs` + poll `GET /jobs/{id}` (or subscribe
  `/jobs/{id}/events`). Replaces v1 `/calc/*` inline calls.
- `/internal/admin/{resource}/all` cache warming → `GET /api/v2/{resource}`.
- `/internal/data/{category}` map markers → `GET /api/v2/geofences/{id}/scanner-data?category=`.
- `/api/v1/convert/data` → `POST /api/v2/geometry/convert`.
- `/api/v1/s2/*` → `/api/v2/s2/*`.

No codegen safety net, but the wrapper is centralized — a bounded edit.

## 11. Open questions / deferred

- **Cursor pagination** — offset is fine at current scale; revisit if a list outgrows it.
- **Scoped / per-user API keys** — single `KOJI_SECRET` today; multi-tenant keys are a future enum
  over the auth validator.
- **Rate-limiting / CORS** — add only if the API goes cross-origin or multi-tenant.
- **`/internal/routes/from_scanner`** — frontend calls it; confirm it folds into a v2 route-import
  endpoint or stays internal during P5 (resolve in writing-plans).

## 12. Testing strategy

- **P0:** proc-macro expansion tests (generated DTO/handler shape); `ResponseError`→status table unit
  tests; pagination math.
- **Per endpoint:** happy path + the error contract (404 missing, 422 semantic, 400 malformed,
  401 unauth). Envelope-shape assertions.
- **Jobs:** create→poll→succeed; `?wait` timeout returns `200` running record (not `504`); cancel.
- **`?format=`:** default enveloped GeoJSON vs each raw export's Content-Type + bare shape.
- **Integration:** Dragonite publish event payload unchanged (contract guard).
- Full-suite run only at phase boundaries.
